# design.md

倉庫工作台的介面設計規範。

---

## 1. 設計前提

- **在哪裡用**：四層樓透天倉庫。光線不一定好，常常一手拿貨、一手拿手機。
- **誰在用**：只有一位熟悉商品的使用者。不需要新手引導，要的是快。
- **主要裝置**：手機（iPhone／Android，PWA 全螢幕）。電腦只做匯入匯出和大量編輯。
- **最常做的事**：找貨、核對出貨、看今天要做什麼。每件事都要在三次點擊內完成。

## 2. 核心概念：螢幕上的標籤＝牆上的標籤

整套介面唯一刻意「搶眼」的地方是**儲位標籤**。

儲位代碼（例如 `4F-T-03`）在螢幕上的樣子，跟貼在倉庫牆上、貨架上的實體標籤**完全一樣**：同樣的字型、同樣的樓層顏色、同樣的版面。使用者在手機上看到綠色的 `1F-A-03`，抬頭找牆上綠色的標籤就對了。

`/locations` 頁面要能直接列印這些標籤（A4 一頁多張），確保螢幕和實體一致。

其餘介面保持安靜、克制，把注意力留給標籤、數量和警告。

## 3. 色彩

### 基礎色

| 名稱 | 淺色模式 | 深色模式 | 用途 |
|---|---|---|---|
| 底 | `#F4F5F3` | `#16181B` | 頁面背景 |
| 面 | `#FFFFFF` | `#202327` | 卡片、列表底 |
| 墨 | `#1E2328` | `#E8EAEC` | 主要文字 |
| 次 | `#5C646D` | `#A3AAB2` | 次要文字 |
| 線 | `#DADDE0` | `#33383E` | 分隔線、邊框 |
| 操作藍 | `#2457D6` | `#7FA2F2` | 主要按鈕、連結、目前分頁 |

### 樓層色（只用在儲位標籤）

| 樓層區域 | 顏色 | 說明 |
|---|---|---|
| 1F | `#2F7D6D` | 一樓（門口到廚房） |
| 3F | `#6A4FB3` | 三樓左側房間 |
| 4F-S | `#9A6B1F` | 四樓神明廳 |
| 4F-T | `#4E6378` | 四樓鐵皮屋倉庫 |

標籤樣式：樓層色實底、白字。深色模式維持同樣實底，確保跟實體標籤一致。

### 狀態色

| 狀態 | 文字 | 背景（淺／深） | 用途 |
|---|---|---|---|
| 正確 | `#2B8A3E` | `#E6F4EA` / `#1D3324` | 掃碼吻合、核對完成 |
| 注意 | `#A86B00` | `#FFF3D6` / `#3A2F14` | 低於安全庫存、待更新平台 |
| 錯誤 | `#C92A2A` | `#FDE8E8` / `#3D1E1E` | 掃錯貨、單號不符 |

狀態色只用來表示狀態，不當裝飾。

## 4. 字型

| 角色 | 字型 | 備註 |
|---|---|---|
| 介面文字 | 系統字型：`"PingFang TC", "Noto Sans TC", "Microsoft JhengHei", system-ui, sans-serif` | 不額外載入中文字型，速度優先 |
| 代碼與數字 | `Barlow Condensed`（Google Fonts），600 字重 | 儲位、貨號、大數字。窄體讓長代碼在手機上不斷行，也有實體標籤的感覺 |

數字一律使用等寬數字（`font-variant-numeric: tabular-nums`），庫存欄位上下對齊。

### 字級

| 用途 | 手機 | 電腦 |
|---|---|---|
| 頁面標題 | 20px / 500 | 22px / 500 |
| 區塊標題 | 17px / 500 | 18px / 500 |
| 內文 | 16px / 400 | 15px / 400 |
| 輔助文字 | 14px / 400 | 13px / 400 |
| 儲位標籤（列表內） | 18px Barlow Condensed | 16px |
| 儲位標籤（找貨結果） | 32px Barlow Condensed | 28px |
| 大數字（可售量） | 28px Barlow Condensed | 24px |

手機最小字級 14px。

## 5. 版型

### 手機

- 底部分頁列 4 個：**今日、找貨、出貨、上架**。其他功能從「今日」頁的入口進入。
- 主要操作放在畫面下半部，拇指搆得到。
- 點擊區域最小 48×48px，列表列高最小 56px。
- 不用卡片堆疊；清單用分隔線列表。

```
今日                          找貨
┌───────────────────┐        ┌───────────────────┐
│ 今日          ⚙   │        │ [ 搜尋 膠條      ]│
│ 待出貨 12 待叫貨 5│        │                   │
│ ⚠ 3 項需更新庫存  │        │ 車門膠條 示意車型 │
│───────────────────│        │ ┏━━━━━━━━━━┓      │
│ □ 匯入蝦皮訂單    │        │ ┃ 4F-T-03  ┃ ← 大標籤
│ □ 問老闆膠條補貨  │        │ ┗━━━━━━━━━━┛      │
│ □ 整理鐵皮屋      │        │ 一車份可售   2    │
│                   │        │ 前左 5  前右 3    │
│───────────────────│        │ 後左 2  後右 4    │
│ 今日 找貨 出貨 上架│        │ 今日 找貨 出貨 上架│
└───────────────────┘        └───────────────────┘
```

找貨結果頁：儲位標籤是畫面上最大的元素。

### 電腦

- 左側固定導覽列，右側主內容區。
- 表格可以寬，但內文行寬保持 80 字元以內。
- 匯入、匯出頁面採步驟式：選平台 → 上傳 → 預覽結果 → 確認。

```
┌──────────┬──────────────────────────────────┐
│ 今日     │ 訂單匯入                          │
│ 找貨     │ 平台 [蝦皮 ▾]   [選擇檔案]        │
│ 出貨     │──────────────────────────────────│
│ 上架     │ 新增 18  取消 2  未對應 1          │
│ ──────── │ 未對應：「膠條 後左 2020款」 [對應]│
│ 訂單匯入 │                                  │
│ 批次匯出 │                                  │
│ 商品     │                                  │
│ 儲位     │                                  │
└──────────┴──────────────────────────────────┘
```

斷點：寬度 ≥ 1024px 切換為電腦版型。

## 6. 元件原則

- **按鈕**：每個畫面最多一個實心主要按鈕，其他用外框或文字按鈕。
- **圓角**：輸入框和按鈕 8px；儲位標籤 4px（模仿實體標籤）；不要讓所有東西都同一個圓角。
- **陰影**：不用。用分隔線和底色區分層級。
- **列表 vs 卡片**：資料列表一律用分隔線列表，不用一張張卡片。
- **數量顯示**：庫存數字靠右對齊；低於安全庫存時數字改成「注意」色，不加額外圖示。

## 7. 出貨核對的回饋

出貨核對是最需要「不用看螢幕也知道結果」的地方：

| 結果 | 視覺 | 聲音 |
|---|---|---|
| 掃到正確商品 | 該列打勾，背景短暫轉「正確」色 | 短促一聲 |
| 掃到錯誤商品 | 全寬「錯誤」橫幅，寫明掃到什麼、應該是什麼 | 明顯不同的兩聲 |
| 全部吻合 | 「核對完成」按鈕啟用 | — |

聲音需在使用者第一次點擊後才能播放（iOS 限制），進入出貨頁時以「開始核對」按鈕觸發。
iOS 不支援震動 API，不要依賴震動。

## 8. 動態

- 只在回應使用者動作時使用：掃碼結果、展開、送出確認。
- 不做進場動畫、不做卡片 hover 動畫。
- 尊重 `prefers-reduced-motion`。

## 9. 文字

- 繁體中文，口語、直接，用倉庫裡實際會講的詞：「找貨」「叫貨」「一車份」「儲位」，不用「庫存單位」「補貨請求」。
- 按鈕寫動作：「匯入訂單」「下載批次檔」「核對完成」，不寫「確定」「送出」。
- 同一個動作從頭到尾用同一個詞：按「匯入訂單」，完成提示寫「已匯入 18 筆訂單」。
- 錯誤訊息寫清楚發生什麼、怎麼處理：「有 1 筆貨號對不到商品，請手動對應。」不道歉、不寫「錯誤：」。
- 空畫面給下一步：「還沒有上架草稿。拍第一張照片開始。」

## 10. 狀態處理

| 狀態 | 處理 |
|---|---|
| 離線 | 頂部細橫幅「離線中，可查詢，變更會在連線後送出」 |
| 待送出佇列 | 「今日」頁顯示待同步筆數 |
| 載入中 | 骨架列表，不用全螢幕轉圈 |
| 空清單 | 一句說明 + 一個動作按鈕 |

## 11. 無障礙與品質底線

- 文字對比至少 4.5:1（包含樓層色上的白字）。
- 所有可點擊元素有可見的鍵盤焦點樣式（電腦版）。
- 不只用顏色傳達意思：錯誤、注意都要有文字說明。
- 淺色與深色模式都要完整測試。

## 12. 實作備註

- 色彩、字級寫成 CSS 變數，掛在 Tailwind 主題上，不在元件裡寫死色碼。
- 儲位標籤做成單一元件 `<LocationTag code="4F-T-03" size="sm|lg|print" />`，螢幕與列印共用。
- `Barlow Condensed` 只載入 600 字重的拉丁字元子集。
