## 專案一句話

替一家多平台電商（蝦皮、露天、奇摩拍賣、酷澎）的倉庫助理做一個**手機優先的 PWA 工作台**：管庫存（含拆賣組合商品）、儲位、出貨核對、上架與任務。**不串平台 API**，資料靠 Excel 匯入匯出。

## 已決定、不要更動的事

- 技術棧：Next.js App Router + TypeScript、Turso（Drizzle）、Cloudflare、R2、Tailwind、Serwist。
- **不呼叫任何電商平台 API。**
- **不自動回寫平台。** 只產生批次檔，由使用者手動上傳。
- **不存顧客個資。** Excel 在瀏覽器端解析，個資欄位在送出前丟棄。伺服器端不應收到姓名、電話、地址、Email。
- 庫存變動一律寫入 `stock_movements`；`skus.stock` 只是快取。
- 組合商品不持有實體庫存，可售量 = 各部件 `floor(庫存 / qty)` 的最小值。
- Anthropic API 只在伺服器端呼叫，模型名稱讀 `CLAUDE_MODEL` 環境變數。
- 介面文字一律繁體中文。

## 尚未確認的事（不要自行假設）

- **各平台 Excel 的實際欄位名稱**：訂單匯出、批次更新範本、批次上架範本都還沒拿到。
  - 先用 `lib/platforms/<platform>/columns.ts` 留出設定檔結構，欄位名稱以 `TODO` 標註。
  - 使用者會提供範本檔放在 `samples/`（已加入 `.gitignore`，因為可能含個資）。拿到後再填欄位。
- 蝦皮批次更新是否能「只改庫存」。
- 各平台批次上架的圖片是用網址還是另外上傳。

遇到這些問題時，停下來問，不要猜。

## 里程碑

每個里程碑完成後停下來，讓使用者驗收，再進行下一個。

### M0 專案骨架

- Next.js + TypeScript + Tailwind 初始化
- Drizzle + Turso 連線，依 `系統結構規劃.md` 第 4 節建立 schema 與 migration
- design.md 的色彩、字型寫成 CSS 變數與 Tailwind 主題
- 手機版底部分頁列（今日、找貨、出貨、上架）與電腦版側邊欄的空殼頁面
- PWA manifest 與 Serwist 基本設定，可加入主畫面

**驗收**：手機加入主畫面後全螢幕開啟，四個分頁可切換；寬螢幕顯示側邊欄。

### M1 儲位與商品

- 儲位 CRUD；`<LocationTag>` 元件（sm / lg / print 三種尺寸）
- 儲位標籤列印頁（A4 多張）
- 商品、SKU CRUD；組合商品設定（選擇部件與數量）
- `lib/stock/`：組合可售量計算函式，**附單元測試**
- 盤點調整：輸入實際數量，寫入 `adjust` 異動

**驗收**：建立膠條四個部件與一車份組合，調整部件庫存後，一車份可售量正確變化。

### M2 找貨

- `/find` 搜尋商品名、貨號
- 結果頁：大尺寸儲位標籤、可售量、組合商品的各部件數量
- 離線可查（Service Worker 快取商品、SKU、儲位、庫存快照）

**驗收**：開飛航模式仍可搜尋並看到儲位。

### M3 蝦皮訂單匯入

- `/import`：選平台、上傳 Excel，瀏覽器端 SheetJS 解析
- `lib/pii.ts` 過濾個資欄位
- 伺服器 upsert 訂單、比對 SKU、寫入異動；重複匯入不重複扣
- 取消訂單把庫存加回
- 結果頁：新增、取消、未對應；未對應可手動選 SKU

**驗收**：同一份檔案匯入兩次，庫存只扣一次；網路請求內容不含任何個資。

### M4 蝦皮批次更新檔

- 「待更新平台庫存」清單
- 產生蝦皮批次更新 Excel 並下載
- 使用者按「已上傳」後才更新 `last_pushed_stock`

**驗收**：完成 MVP 循環——賣掉一條前左 → 匯入訂單 → 一車份可售量下降 → 批次檔包含一車份與前左的新數量。

**M4 完成即為 MVP。** 之後順序：上架模組 → 出貨核對 → 叫貨清單 → 任務收件匣 → 其他三平台轉接。

## 開發慣例

- 小步提交，每個 commit 只做一件事。
- 修改資料庫 schema 前先說明理由並詢問。
- 庫存計算、訂單匯入、個資過濾這三塊必須有測試。
- 平台差異只能出現在 `lib/platforms/` 裡，其他地方不寫 `if (platform === 'shopee')`。
- 不新增本文件沒提到的大型依賴套件，需要時先詢問。
- 程式碼註解與 commit 訊息可用英文；介面文字用繁體中文。

## 使用者背景

- 熟悉 Next.js、TypeScript、Turso、Cloudflare，能讀英文技術文件。
- 課餘時間開發，每次工作時段有限，請讓每個步驟都能獨立完成、獨立驗收。
